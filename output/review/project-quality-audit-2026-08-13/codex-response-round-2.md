# 對 Round 2 發現的回應

## 接受

- C2 尚缺 Windows Chrome／Edge 真實 pointer 整合證據。依 rubric，不能用雙軸數學與靜態 wiring 測試替代。

## 已完成的可自動修正

- 流程 Scene 拖曳改為單一 undo 交易。
- Scene／流程四向、縮放倍率與輕點門檻加入決定性測試。
- 模板與 Scene 複製完整重映射錨點及資源 ID。
- ZIP 解壓前預檢，內建字型及文件狀態同步。

## 封閉條件

部署 0.18.0 後，以 Windows Chrome 或 Edge 完成以下最短矩陣：

1. Scene 空白處向上下左右平移。
2. 橫版與直版各拖一個物件，確認手感一致且輕點不移動。
3. 流程空白處向上下左右平移。
4. 拖曳流程 Scene 卡片後按一次 Undo，確認回到拖曳前位置。
5. Shift 等比縮放與 Shift 旋轉 90 度。
6. 開啟右鍵選單並執行「找回畫面中央」。

通過後可進行 Round 3 並封閉 C2；若任一失敗，依具體重現步驟修正後再審。
