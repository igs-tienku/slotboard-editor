# SlotBoard v0.22.0 流程 Scene 預覽與卡片縮放

## 目標

讓流程大畫布中的每張 Scene 卡片預設顯示完整 Scene 畫布，依橫版、直版、方形與極端比例自動適配；使用者可拖曳卡片右下角獨立調整尺寸，預覽在任何合法尺寸下都保持完整、不裁切、不拉伸。

## 輸入與限制

- 既有 SlotBoard v0.21.2 程式與 `.slotboard` schema v3。
- 保留流程大畫布雙軸平移、Scene 卡片移動、連線標註、Ctrl＋滾輪縮放、Undo 與自動整理。
- 桌面單機工具，不新增登入或協作功能。
- 沒有指定參考圖；以可觀察行為、原始長寬比與自動化證據驗收。

## 交付物

- `app/editor.tsx`：完整預覽、卡片移動與縮放互動、連線幾何。
- `app/globals.css`：可變卡片版面、完整畫布 `contain` 預覽與縮放控制點。
- `lib/editor-model.js`：預設尺寸算法、尺寸限制、持久化、舊檔相容與自動排列。
- `lib/interaction-math.js`：流程卡片縮放手感算法。
- 對應測試、README、v0.22.0 版本資訊及可部署建置。
- 本目錄內的凍結交付說明、客觀檢查、原始及驗證後審核結果。

## 不在範圍內

- 改變 Scene 編輯畫布本身的內容或尺寸。
- 流程卡片旋轉、多人協作、時間軸。
- 將流程縮圖作為正式輸出圖檔。
