# 任務

## 目標

在完整檢查 SlotBoard 互動狀態後，修正物件可能意外移到 Scene 底部、Scene Ctrl＋滾輪縮放可能跳回舊比例，以及大字級造成右側對齊面板重疊的問題；不得破壞拖曳、平移、縮放、復原、PSD 輸出或其他既有功能。

## 輸入與素材

- 使用者回報：操作右側圖層／屬性欄或點擊找回中央後，物件偶爾移到最下方。
- 使用者回報：Scene Ctrl＋滾輪縮放後偶爾彈回縮放前狀態。
- 不合格截圖：[右側屬性面板重疊](assets/unqualified/properties-overlap-before.png)。比較重點為六個對齊按鈕、兩個等距按鈕與找回中央按鈕發生垂直重疊；不要求模仿截圖裁切或瀏覽器外框。
- v0.19.0 commit `e653d2e` 是修正前可回復基準。

## 交付物

- 右欄數字輸入滾輪保護與中斷拖曳清理。
- 使用同步縮放 ref 的 Scene 密集滾輪處理。
- 超大物件也能正確縮放後置中的定位算法。
- 大字級下不重疊的對齊操作面板。
- 自動測試、效能基準、PSD 驗證、Lint、版本與內審紀錄。

## 不在範圍內

- 不改變 Scene／流程的資料模型概念。
- 不取消數字欄位的鍵盤輸入或上下箭頭操作。
- 不重新設計整個右側屬性欄。
