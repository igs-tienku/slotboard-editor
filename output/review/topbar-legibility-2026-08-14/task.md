# 任務

## 目標

修正 SlotBoard 頂部工具列的 Scene／流程模式按鈕在 Chrome 中因固定 34px 寬度造成文字裁切與辨識不清的問題。兩個按鈕應取得足夠但不誇張的寬度，完整顯示文字，並維持清楚的選取狀態。

## 輸入與素材

- 使用者回報截圖：[Chrome 修正前](assets/unqualified/chrome-topbar-before.png)。比較重點為畫面中央的 Scene／流程按鈕：文字被擠壓、邊界過近，且按鈕沒有取得頂部剩餘空間中的合理寬度。截圖只作為缺陷證據，不要求模仿瀏覽器外框或裁切範圍。
- 現有 v0.18.1 程式碼與 Git commit `793916b` 是修正前的可回復基準。
- 使用者指定所有審核項目至少 90 分；最多 5 輪。

## 交付物

- `app/editor.tsx`：模式按鈕具備專用 class 與可辨識的選取狀態語意。
- `app/globals.css`：模式按鈕有足夠寬度、內距、單行文字及清楚對比。
- `tests/rendered-html.test.mjs`：加入防止固定窄寬度回歸的檢查。
- v0.18.2 建置、測試、Lint 與本次內部審核紀錄。

## 不在範圍內

- 不重設整個頂部工具列的品牌、歷史或檔案操作區。
- 不改變 Scene／流程切換行為。
- 不處理使用者未回報的全站視覺改版。
