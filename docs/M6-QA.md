# SlotBoard M6 驗收紀錄

- 版本：0.7.0
- 日期：2026-08-13
- 目標平台：Windows Chrome／Microsoft Edge

## 已自動驗證

- 50 Scene × 100 圖層（共 5,000 圖層）可序列化並完整還原，預算上限 3 秒。
- `base: "./"` 的靜態建置可在子路徑載入，產物不含站台根目錄絕對資產路徑。
- 復原／重做快捷鍵不會攔截文字欄位原生編輯。
- Delete／Backspace 可刪除選取圖層；Escape 可清除選取並關閉輸出視窗。
- 鍵盤焦點有明顯外框；輸出視窗具 dialog、標題與進度狀態語意。
- 全套建置、PSD round-trip、資料模型、專案包、匯出與壓力測試通過。

## 人工驗收待辦

- 目前 Codex 環境沒有可連接的瀏覽器實例，因此 Chrome／Edge 的實際點擊、Tab 順序與重新整理驗收待補。
- 由編輯器實際匯出的 PSD，請分別以 Krita 與可用的 Photoshop 版本開啟，確認圖層順序、群組、隱藏、透明度與中文名稱。
- 以 5 個歷史企劃案例計時，確認至少 4 個案例不需要外部繪圖工具即可完成示意圖。

執行 `npm run test` 可重跑完整驗證；`npm run benchmark` 可單獨重跑 5,000 圖層壓力測試。
