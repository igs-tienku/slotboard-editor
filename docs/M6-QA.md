# SlotBoard M6 驗收紀錄

- 版本：0.7.0
- 日期：2026-08-13
- 目標平台：Windows Chrome／Microsoft Edge

## 已自動驗證

- 50 Scene × 100 圖層（共 5,000 圖層）可序列化並完整還原，預算上限 3 秒。
- `base: "./"` 的靜態建置可在子路徑載入，產物不含站台根目錄絕對資產路徑。
- 復原／重做快捷鍵不會攔截文字欄位原生編輯。
- Delete／Backspace 可刪除選取圖層；Escape 可清除選取並關閉輸出視窗。
- 鍵盤焦點有明顯外框；輸出視窗具 dialog、標題與進度狀態語意。
- 全套建置、PSD round-trip、資料模型、專案包、匯出與壓力測試通過。

## 人工驗收待辦

- 目前 Codex 環境沒有可連接的瀏覽器實例，因此 Chrome／Edge 的實際點擊、Tab 順序與重新整理驗收待補。
- 由編輯器實際匯出的 PSD，請分別以 Krita 與可用的 Photoshop 版本開啟，確認圖層順序、群組、隱藏、透明度與中文名稱。
- 以 5 個歷史企劃案例計時，確認至少 4 個案例不需要外部繪圖工具即可完成示意圖。

執行 `npm run test` 可重跑完整驗證；`npm run benchmark` 可單獨重跑 5,000 圖層壓力測試。

## M6.1 回歸重點

- 輕點物件後移動滑鼠，不應改變物件位置。
- 將物件拖向四邊，物件不可整個離開畫布；「找回畫面中央」須能救回舊資料中的越界物件。
- Shift 拖曳右下縮放點須維持原比例；Shift 旋轉須落在 90 度倍數。
- 在畫布物件與圖層列按右鍵，應顯示合法操作選單。
- 新建專案與舊 `.slotboard` 的背景須位於最下層；匯出 PSD 後以 Krita 檢查同一順序。

## M6.2 PSD 群組修正

- PSD 葉圖層現在會累積所有父群組的位移、旋轉與翻轉，再光柵化到 Scene 座標。
- 圖層及群組透明度只保留為 PSD opacity，不再同時烘焙進像素造成雙重透明。
- `tests/scene-psd-roundtrip.test.mjs` 會建立真實 Scene，輸出並重新解析 PSD，逐像素邊界檢查群組物件、透明度與背景順序。
- 可用 `node scripts/create-scene-psd-regression.mjs` 產生 Krita 人工驗收檔。

## M7 圖形外觀驗收

- 選取矩形、圓形、三角形、星形或多邊形時，屬性面板應顯示五級具名灰階與彩色色盤。
- 自訂填色、外框色與外框寬度應同步反映在畫布與 PSD。
- 矩形圓角應同步反映在畫布、專案重開與 PSD。
